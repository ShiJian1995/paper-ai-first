# 期刊匹配

锁定论文 ID，使用该论文的摘要、方法、贡献、局限、篇幅、用户预算与期刊偏好。选题时可初筛，结果完成后重新匹配。

检索期刊/出版商官方页面，记录来源与核查日期。比较范围和文章类型、近期相近文章、篇幅/图表、数据代码要求、AI 使用披露、开放获取选项与实际费用币种。JCR/中科院分区等只能使用当年可验证来源；无访问权限则标记未知。不要从名称或历史记忆猜测影响因子、分区、审稿时间或录用概率。

输出 `submission/journals.json` 与简明推荐理由。费用区分可选开放获取和必付费用。模板下载后固定版本。按目标要求准备 cover letter 和声明草稿，作者、伦理、资金、利益冲突等事实未知时标记待补，不生成虚构声明。

期刊选择与实际投稿分离。用户没有明确授权时仅生成材料，不联系编辑、不填写最终声明、不提交稿件。
